04. 페이지 작성 방법

  1. src/pages/guide.html을 복사해 새 HTML을 만듭니다.
  2. src/data/site.js에 페이지 제목과 설명을 등록합니다.
  3. 필요한 SCSS와 JavaScript를 작성하고 연결합니다.
  4. npm run check로 검사한 뒤 dist/를 전달합니다.
